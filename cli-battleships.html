How to play

  1. Choose a board size (up to 10×10) and how many ships each side gets.
  2. Ships are one square each and placed at random.
  3. Fire by typing a row and column, like 2 3.
  4. Sink all the computer's ships before it sinks yours.

One game, three ways of thinking

Each version follows the same rules, but its structure comes from how its language wants you to write code.

PYTHON_battleships.py

Python Object-oriented

class BattleshipGame:
    def __init__(self):
        self.player_grid = [['~'] * GRID_SIZE
                            for _ in range(GRID_SIZE)]
        self.computer_ships = []
        self.computer_guesses = set()

    def check_winner(self):
        if not self.player_ships:
            return "Computer"
  • All of the game's state lives on one BattleshipGame object.
  • Each step of the game is a method that reads and updates self.
  • Bad input is caught with try / except ValueError.
C_battleships.c

C Procedural

void placeShips(
    char grid[MAX_GRID_SIZE][MAX_GRID_SIZE],
    int size, int numShips) {
    int shipsPlaced = 0;
    while (shipsPlaced < numShips) {
        int x = rand() % size;
        int y = rand() % size;
        if (grid[x][y] == '~') {
            grid[x][y] = 'S';
            shipsPlaced++;
        }
    }
}
  • The boards are fixed-size char arrays, changed in place.
  • Plain functions pass counters around by pointer (int *shipsLeft).
  • Input is checked by hand using scanf's return value.
RUST_battleships.rs

Rust Functional-style

fn place_ships(grid_size: usize, num_ships: usize,
               ships: HashSet<Position>)
               -> HashSet<Position> {
    if ships.len() == num_ships {
        ships
    } else {
        let x = rand::thread_rng().gen_range(0..grid_size);
        let y = rand::thread_rng().gen_range(0..grid_size);
        place_ships(grid_size, num_ships,
            ships.into_iter()
                 .chain([(x, y)].iter().cloned())
                 .collect())
    }
}
  • Ship placement and the game loop are recursive rather than loops.
  • Grids and ship sets are passed into functions and handed back, rather than changed in place.
  • match on each parse() result checks the input.
